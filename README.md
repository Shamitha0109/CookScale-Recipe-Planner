# CookScale – Recipe Scaling and Smart Grocery Planner

## Project Overview

CookScale is a Python-based application designed to simplify recipe scaling and weekly meal planning. It adjusts ingredient quantities according to the required servings, generates a combined grocery list, and estimates the total grocery cost.

## Key Features

- View available recipes and ingredients.
- Scale recipes according to the required servings.
- Plan meals for seven days.
- Generate a combined grocery list.
- Calculate estimated grocery costs.
- Validate user inputs.

## Technologies Used

- Python 3
- Git
- GitHub

## How to Run

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run:

```bash
python cookscale.py
```
